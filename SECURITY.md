# Security Policy

## Supported Versions

Only the latest release of 3LCS receives security fixes.

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |
| Older   | ❌        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Use GitHub's [private vulnerability reporting](../../security/advisories/new)
to report issues confidentially. This keeps the details out of public view
until a fix is available.

Please include as much of the following as possible:

- Type of issue (e.g. credential exposure, path traversal, code injection)
- Full path of the affected source file(s)
- Location of the affected code (tag, branch, commit, or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept code (if possible)
- Impact of the issue and how an attacker might exploit it

I aim to respond within **7 days** and to publish a fix or mitigation
within **30 days** of confirmed issues.

## Preferred Languages

English or Polish.
